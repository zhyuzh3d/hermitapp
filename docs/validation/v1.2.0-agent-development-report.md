## 交付功能与授权合同

应用库 → 设置 → 智能体开发模式，提供局域网地址、六位随机密码、复制接入信息、修改密码和停止按钮。每个请求只校验当前唯一密码，不配对、不登记电脑、不绑定来源 IP、不发放独立客户端令牌，也不限制应用白名单。多个客户端共享密码；重启和升级保留密码。修改后旧密码失效；代码激活和 UI 动作在执行前重新校验，已提交事务不撤销。原单应用部署与新模式互斥，改密会关闭旧部署入口。

实现 12 个标准 MCP 工具：指南、运行状态、应用列表/详情、新建本地应用、代码文件列表/读取/增量更新、打开/刷新、版本列表/回滚。整包目录和二进制通过同一服务的认证 ZIP PUT 发布。代码更新复用安装事务、路径/体积验证、不可变 release、版本条件更新和幂等控制，保留应用身份、业务数据和授权。Python watch 在另一台电脑修改代码后停止并要求合并，不静默覆盖新版。

手机提供实时 discovery、SKILL.md、MCP tools/resources/prompts、页面创作规范和 API 类型；guidanceVersion 覆盖指南、创作规范和 API 定义。构建会检查打包文档与仓库源文件一致。Python 标准库助手支持私密输入/保存密码、调用、目录发布、监听刷新、stdio 转接和轻量动态 Skill 安装。Skill 只保留实时获取规则，不保存密码或固定功能目录。按 skill-creator 的要求明确触发范围、任务授权与不可信代码边界；客户端安装和 MCP 注册不冒充为服务端能自动完成的动作。
