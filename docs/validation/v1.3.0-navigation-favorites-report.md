## 实现结论

- 底部导航固定为收藏、全部、开发、设置、支持五个等宽 Tab；每个按钮与其固定尺寸图标容器共用中心线。
- 收藏是 `WebAppInstance.favorite` 持久字段。Registry schema 由 v3 升级到 v4，旧实例默认不收藏；爱心切换、过滤和从收藏页新增的默认值走同一 Native 真值。
- 收藏与全部复用列表、搜索、类型筛选、扫码和添加面板，不维护两套页面或应用副本。
- 开发页开关直接控制全局智能体服务；绿色状态点来自周期读取的 Native 服务状态，不用前端猜测。
- 设置页包含主题、恢复、完整离线图标库、运行诊断、许可、版本、应用标识、作者 `10knet·zhyuzh3d` 和 GitHub 仓库入口。
- 支持页先进行 7 秒上限的 HTTPS 预检；可用时进入无 Bridge、拒绝网页权限请求的独立 Profile，不可用或主文档加载失败时回到本地重试页。
- 二维码使用 Google Play 服务 Code Scanner 的系统 UI，仅允许 QR 中的 HTTP(S) URL，结果预填而不自动安装；没有额外申请相机权限。
